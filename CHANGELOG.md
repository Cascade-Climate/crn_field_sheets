# Changelog

All edits to the field sheets in this directory are recorded here so they can be replayed
into the layout files at `C:\Users\nic\crn_data\sheets\layouts\` when it is time to merge
back. Without this record, a change made here is a one-way fork.

## Format

One entry per change. Group by date, newest first.

```
### YYYY-MM-DD

- **V<N>** `<section id or element>` — <what changed, before → after if a rename>.
  *Why: <motivation>.*
```

When a single edit touches the same element across multiple sheets (e.g. rewording the
sign-off gate text on all thirteen), record it once and list every affected sheet.

## Log

*(Newest first. The initial copy of sheets into this directory is not an edit.)*
